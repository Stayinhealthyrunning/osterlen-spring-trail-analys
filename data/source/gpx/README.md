# GPX source archive

Filnamnsstandard:

`ost-<race-family>-<year-or-year-range>-<provenance>.gpx`

Exempel:
- `ost-ultra60-2024-organizer.gpx`
- `ost-ultra60-2025-2026-organizer.gpx`

Lägg aldrig in en tom/konstruerad placeholder med `.gpx`-ändelse. Kända källor och planerade målfilnamn finns i `config/course-source-manifest.json`.

`duo60` har ingen egen GPX-mapp eftersom Duo använder motsvarande års `ultra60`-geometri.
